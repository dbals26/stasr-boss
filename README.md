# 스타서버 보스 현황 페이지

스타서버의 공개 `/api/live` 엔드포인트에서 `bosses` 배열만 추려서 표시하는 비공식 웹페이지입니다. 모바일/PC 대응, 검색, 정렬, 15초 갱신, 출현 예정 시간 카운트다운을 지원합니다.

## Vercel에 인터넷 주소로 공개하기

1. https://github.com 에 로그인하고 새 저장소를 만듭니다.
2. 이 ZIP 압축을 풀어 나온 파일(`index.html`, `api/bosses.js`, `vercel.json`, `package.json`)을 저장소 루트에 업로드합니다. **압축파일 하나만 올리면 안 됩니다.**
3. https://vercel.com 에 GitHub로 로그인하고 **Add New → Project → 저장소 선택 → Deploy**를 선택합니다. Framework Preset은 **Other**(또는 자동 감지), Root Directory는 저장소 루트로 유지합니다.
4. 배포가 끝나면 `https://프로젝트명.vercel.app` 주소를 PC/휴대폰에서 엽니다.

## 주의사항

- 실제 사이트 API는 이 개발 환경에서 직접 확인되지 않았습니다. 사용자 개발자도구 스크린샷의 `bosses`, `name`, `status`, `next_spawn_at`, `interval_minutes` 등을 기준으로 작성했습니다.
- 서버가 외부에서의 API 요청을 제한하거나, 데이터 구조가 다르거나, 호스팅 측 서버리스 IP를 차단하면 연결 오류가 날 수 있습니다.
- `status`가 예상과 다른 값이면 화면에 서버에서 보낸 원래 문자열을 보여줍니다. 실제 값에 맞춰 상태 분류를 조정할 수 있습니다.
- 원본 API의 이용약관, 호출 제한과 공개 범위를 확인한 뒤 사용하세요.
- 이 프로젝트는 **배포 준비 완료한 소스**이며, 배포와 실시간 작동 여부 검증까지 완료한 것은 아닙니다.
